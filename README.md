# ตัวดึงลิงก์รูปภาพ

เว็บแอปสำหรับสแกนรูปภาพจากหน้าเว็บเชิงลึก และคัดลอกที่อยู่ (URL) ของไฟล์ต้นฉบับ

## วิธีใช้งาน

ดับเบิลคลิก `run.bat` — สคริปต์จะติดตั้งไลบรารีและเปิดเบราว์เซอร์ให้อัตโนมัติ

หรือรันด้วยตนเอง:

```
pip install -r requirements.txt
python app.py
```

## ระดับความลึกในการสแกน

**ระดับ 1 — มาตรฐาน**
`<img src>` · `srcset` · `<picture><source>` · lazy-load ทุกรูปแบบ (`data-src`, `data-original`, ฯลฯ) ·
`og:image` / `twitter:image` · favicon · `background-image` ใน inline style · ลิงก์ `<a>` ที่ชี้ไฟล์รูปโดยตรง

**ระดับ 2 — ละเอียด** (เพิ่มจากระดับ 1)
ไฟล์ CSS ภายนอกและ `@import` ซ้อน · ไฟล์ JavaScript ในโดเมนเดียวกัน · สคริปต์ในหน้า ·
JSON-LD (schema.org) · `<noscript>` · `<svg><image>` · `<video poster>` / `<object>` / `<embed>` ·
แอตทริบิวต์ `data-*` ทุกตัวบนทุกแท็ก · URL ที่ถูก escape ในโค้ด (`\/`, `/`)

**ระดับ 3 — ลึกที่สุด** (เพิ่มจากระดับ 2)

- สแกน `<iframe>` ในโดเมนเดียวกัน
- ตามลิงก์หน้าย่อยในเว็บไซต์เดียวกัน (เปิดใช้ได้จากตัวเลือก สูงสุด 12 หน้า)
- ตรวจสอบทุกลิงก์แบบขนานและตัดลิงก์เสียทิ้งอัตโนมัติ
- **สืบค้นไฟล์ต้นฉบับความละเอียดสูง** — ลองย้อนรูปแบบการย่อขนาดที่พบบ่อย
  แล้วยืนยันด้วยขนาดไฟล์จริงก่อนเพิ่มเข้ารายการ:
  - `name-800x600.jpg` → `name.jpg`
  - `name_thumb.jpg` / `name-small.jpg` → `name.jpg`
  - `/thumb/`, `/thumbs/`, `/resized/`, `/cache/` → `/`
  - `?w=400&quality=70` → ตัดพารามิเตอร์ย่อขนาดออก
  - MediaWiki `/thumb/a/ab/File.jpg/220px-File.jpg` → `/a/ab/File.jpg`
  - Cloudinary `/w_300,h_200/` → ตัดออก
  - Google/Blogger `=s320-c` → `=s0`

## ความสามารถของหน้าเว็บ

- แสดงความคืบหน้าแบบเรียลไทม์ระหว่างสแกน (ขั้นตอนจริง ไม่ใช่ตัวหมุนลอย ๆ)
- สรุปสถิติ: จำนวนที่พบ ปริมาณข้อมูลรวม หน้าที่สแกน ไฟล์ต้นฉบับที่พบเพิ่ม ลิงก์เสียที่ตัดออก
- ค้นหา · กรองตามนามสกุล / แหล่งที่พบ / ขนาดขั้นต่ำ · เรียงตามขนาดหรือชื่อ
- มุมมองรูปภาพและมุมมองตาราง · คลิกภาพเพื่อดูขนาดเต็ม
- คัดลอกลิงก์เดี่ยว หรือคัดลอกหลายรายการพร้อมกัน
- บันทึกไฟล์เดี่ยว หรือรวมเป็น ZIP (ดาวน์โหลดแบบขนาน)

## โครงสร้างไฟล์

```
app.py                 เว็บเซิร์ฟเวอร์และ API
scraper.py             ตรรกะการสแกนเชิงลึก
templates/index.html   หน้าเว็บ
requirements.txt       รายการไลบรารี
run.bat                สคริปต์เริ่มใช้งานสำหรับ Windows
```

## ข้อจำกัด

- อ่านเนื้อหาที่เซิร์ฟเวอร์ปลายทางส่งกลับมา หน้าเว็บที่สร้างรูปด้วยสคริปต์ทั้งหมดหลังโหลด
  อาจดึงได้ไม่ครบ — ระดับ 2 ขึ้นไปช่วยได้มากเพราะอ่านจากไฟล์สคริปต์ด้วย
- หน้าที่ต้องเข้าสู่ระบบก่อนจะเข้าถึงไม่ได้
- โปรดตรวจสอบลิขสิทธิ์และเงื่อนไขการใช้งานของเว็บไซต์ต้นทางก่อนนำภาพไปใช้
